JavaScript Data Types + JSDoc

Interactive examples of JavaScript data types, arrays, objects, functions and JSDoc type information.

1. String

A string represents text.

2. Number

JavaScript uses the Number type for integers and decimal numbers.

3. BigInt

BigInt is used for very large integers.

4. Boolean

Boolean has only two values: true or false.

5. Undefined

A declared variable without an assigned value has the value undefined.

6. Null

null intentionally represents the absence of a value.

7. Symbol

A Symbol creates a unique primitive value.

8. Object

Objects store data as key-value pairs.

9. Array

An array stores multiple values in an ordered collection.

10. Array of Objects

Arrays can contain multiple objects. This is very common with API responses.

11. Function

A function can accept parameters and return a value.

12. typeof

typeof tells us the runtime type of a JavaScript value. 



    



    

    


        
13. JSDoc Type Information


        

            JSDoc provides type information to development tools.
            It does not change JavaScript runtime behaviour.
        



        

        
13.1 Variable Type Annotation


        

            @type documents the expected type of a value.
        


        

        



        

        
13.2 JSDoc vs Runtime Conversion


        

            JSDoc does not convert a value.
            JavaScript functions such as Number()
            perform actual runtime conversion.
        


        

        



        

        
13.3 Object Type


        

            JSDoc can describe the expected structure of an object.
        


        

        



        

        
13.4 Array Type


        

            string[] describes an array whose elements
            are expected to be strings.
        


        

        



        

        
13.5 Function Type Information


        

            @param describes function parameters and
            @returns describes the returned value.
        


        

        



        

        
13.6 Type Assertion


        

            A JSDoc type assertion provides development tools
            with a more specific type interpretation.
            It does not convert the runtime value.
        


        

        



        

        
13.7 DOM Type Assertion


        

            JSDoc can provide more specific information about
            a DOM element.
